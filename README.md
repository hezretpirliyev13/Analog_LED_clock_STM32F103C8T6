# Analog_LED_clock_STM32F103C8T6
As Salam alaikum.
Here i upload the Analog LED clock based on STM32F103C8T6 through PlatformIO framework. i searched on the internet DS3231 library for Bluepill board unfortunately i didn't find that library and i decided to make DS3231 library then i just made simple DS3231 library and path location /lib/DS3231 . I added Bounce, Encoder libraries too. So I want to add more features in future. First of all to add rotary encoder. Here i want to guide you to setup that project. Please follow my instructions
1. Download that github repository.
2. Unzip the zip file and open the Visual Studio on your PC or laptop.
3. On home page select open project and select the unzipped project folder
4. And press th build icon on your VSCode and upload that sketch to your microcontroller.
Thanks for following the instruction steps. May Allah SWT bless all of us, brothers & sisters
# Hardware
1. STM32F103C8T6 or BluePill board
2. DS3231 RTC Module
3. WS2812 LED Strip
4. Wires
5. CR2032
6. 5V Power supply
